# AO Forge v0.1.4 Release Notes

AO Forge `v0.1.4` advances governed issue repair, durable GoalRun operation,
and exact-head AO Stack qualification across the factory and execution layer.

## What Changed Since v0.1.3

- Add bounded governed issue-repair execution with exact source identity,
  machine-bound reproduction evidence, mutation limits, and durable results.
- Strengthen GoalRun and plan-execution ownership, checkpoint recovery,
  retained evidence, and fail-closed mutation guards.
- Qualify immutable native candidates rather than rebuilding cross-compiled
  release archives in the publisher.
- Add a source-owned signed-tag producer and protected draft finalizer so tag
  creation and draft-to-public transitions are recorded and replayable.
- Bind publication to the exact rehearsal run, source commit, approved manifest,
  candidate digests, and immutable promotion-plan digest.

## Supported Artifacts

The public release contains native archives for:

- Linux x86_64
- macOS aarch64
- Windows x86_64

Each public archive is byte-identical to the corresponding immutable rehearsal
candidate, while retaining the established public asset names. Checksums,
GitHub artifact attestations, release-preview evidence, the evidence bundle,
and the immutable promotion plan accompany the archives.

## Verification

Before publication, the rehearsal must pass on all native hosted platforms and
produce a canonical promotion plan. The signed tag producer must verify that
plan without creating a release. Release Publish may create only the exact
reviewed draft, and Release Finalize may only change that verified draft to
public. Public Release Verify and Release Install Verify remain required after
finalization.

## Safety Boundaries

AO Forge executes only explicitly authorized repository work. Release
readiness does not grant publication authority, dry runs create no tag or
release, and the publication path cannot call model providers, broaden
credentials, or substitute rebuilt candidates.
