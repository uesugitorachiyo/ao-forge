# AO Forge v0.1.0 Release Notes

AO Forge v0.1.0 is a controlled preview release for the AO Forge factory
foundation. It is not production-stable infrastructure yet.

## Release Identity

- Tag: `v0.1.0`
- Commit: `861b91b7c0234117504b6e48bb6ef7c075770c3a`
- Repository: `github.com/uesugitorachiyo/ao-forge`
- Release status: controlled preview

## What Is Included

- Go CLI skeleton for deterministic factory planning and packet inspection.
- Local Covenant decision fixture gate behavior.
- Factory brief, factory plan, factory packet, Covenant decision, and Covenant
  gate result contracts.
- Release preview audit and inspect contracts.
- Release artifact inventory and release attestation plan contracts.
- Stable SHA-256 checksum manifest generation and checksum verification.
- Non-mutating Release Preview and tagged Release Rehearsal workflows.
- First public release checklist, branch protection runbook, and release threat
  model.

## Supported Preview Artifacts

The expected public artifact inventory defines these required preview
platforms:

- `linux-amd64`: `dist/ao-forge_Linux_x86_64.tar.gz`
- `darwin-arm64`: `dist/ao-forge_Darwin_arm64.tar.gz`
- `windows-amd64`: `dist/ao-forge_Windows_x86_64.zip`

Each artifact must be covered by `checksums.txt` and by the release attestation
plan before publishing.

## Operator Notes

Treat this release as a preview of AO Forge release controls and factory
contracts. Do not present it as a broad production-stable release.

Before publishing, confirm that:

- the public tag points at the intended commit;
- the uploaded archives match the supported preview artifacts above;
- `checksums.txt` matches every uploaded archive;
- attestation evidence is attached or linked according to the attestation plan;
- these release notes contain only public repository information.

## Known Limitations

- AO2 execution remains governed by the adapter and gate path.
- Release Attestation produces and verifies GitHub Artifact Attestations, but
  the final publish action is still manual.
- A signed-tag or signed-evidence-bundle policy is still future hardening.
- AO2 Pulse should be used only as a local-only, non-mutating task assistant
  until AO Forge's release policy surface is stronger.
