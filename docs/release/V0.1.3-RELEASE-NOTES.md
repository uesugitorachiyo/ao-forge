# AO Forge v0.1.3 Release Notes

AO Forge v0.1.3 is production-stable for solo-operator adoption of the AO Forge
factory brain. It extends the v0.1.2 release foundation with durable GoalRun
contracts, AO2 Pulse readiness handoff controls, retained evidence policy
checks, and a repository production-readiness audit gate.

## Release Identity

- Tag: `v0.1.3`
- Commit: `74a637cf1bedfe01a499adfb4dccdac3c9f76088`
- Repository: `github.com/uesugitorachiyo/ao-forge`
- Release status: production-stable for solo-operator adoption
- Production Promotion passed for `v0.1.3` and remained read-only.

## What Changed Since v0.1.2

- Added durable GoalRun contracts for AO Forge task lifecycle tracking.
- Added GoalRun validation, transition checks, guarded updates, and update audit
  evidence.
- Added AO2 Pulse GoalRun loop documentation and a readiness entrypoint.
- Added GoalRun evidence freshness, linting, retained evidence metadata, and
  negative fixtures.
- Added retained readiness audit provenance checks and stale-evidence blocking.
- Added production-readiness audit command and CI gate.
- Added retained evidence cleanup dry-run evidence to the production-readiness
  artifact.
- Added AO Command v0.1 design for the read-only operator command surface that
  consumes AO Forge evidence before ao-arena work begins.
- Kept public provenance evidence mandatory for promotion-related controls.

## Operator Notes

For corrective releases or follow-up publication work, confirm that:

- the public tag is signed by an active signer and points at the intended commit;
- the uploaded archives match the supported artifacts above;
- `checksums.txt` matches every uploaded archive;
- attestation evidence is attached or linked according to the attestation plan;
- these release notes contain only public repository information.

## Known Limitations

- Production-stable status is scoped to solo-operator adoption.
- Broader multi-user or unattended production infrastructure still needs
  additional product-surface hardening and operational soak evidence.
- AO2 Pulse should remain gated by GoalRun readiness evidence and should not
  bypass AO Forge release or evidence policy checks.
