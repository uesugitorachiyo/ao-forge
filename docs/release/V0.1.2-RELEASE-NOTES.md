# AO Forge v0.1.2 Release Notes

AO Forge v0.1.2 is a controlled preview release candidate for the AO Forge
factory foundation. It is not production-stable infrastructure yet.

## Release Identity

- Tag: `v0.1.2`
- Commit: supplied by the generated Release Publish notes
- Repository: `github.com/uesugitorachiyo/ao-forge`
- Release status: controlled preview

## What Is Included

- Go CLI skeleton for deterministic factory planning and packet inspection.
- Local Covenant decision fixture gate behavior.
- Factory brief, factory plan, factory packet, Covenant decision, and Covenant
  gate result contracts.
- Release preview audit and inspect contracts.
- Release artifact inventory and release attestation plan contracts.
- Release evidence bundle, install verification, rollback audit, and production
  promotion audit contracts.
- Stable SHA-256 checksum manifest generation and checksum verification.
- Non-mutating Release Preview and tagged Release Rehearsal workflows.
- Read-only Release Verify, Release Install Verify, Release Rollback
  audit-only, and Production Promotion evidence workflows.
- Workflow linting in CI to catch GitHub Actions context and expression errors.

## Supported Preview Artifacts

The expected public artifact inventory defines these required preview
platforms:

- `linux-amd64`: `dist/ao-forge_Linux_x86_64.tar.gz`
- `darwin-arm64`: `dist/ao-forge_Darwin_arm64.tar.gz`
- `windows-amd64`: `dist/ao-forge_Windows_x86_64.zip`

Each artifact must be covered by `checksums.txt` and by the release attestation
plan before publishing.

## Verification Evidence

- Post-merge CI on Ubuntu, macOS, and Windows must pass for the release commit.
- Post-merge Release Preview must pass for the release commit.
- Release Rehearsal must pass for `v0.1.2` before Release Publish runs.
- Release Publish must create a reviewed draft release for `v0.1.2` before any
  public release publication.
- Release Verify must pass with default signed-tag and evidence-bundle gates.
- Release Install Verify must pass for the public release assets.
- Release Rollback audit-only must pass without mutating the release.
- Production Promotion must remain read-only and should pass only after the
  required soak window and evidence review.
- Release evidence assets include `release-preview-inspect.json`,
  `checksums.txt`, `release-evidence-bundle.json`,
  `release-evidence-bundle.attestation.json`, and the `*.attestation.json`
  files.
- Release preview evidence for `v0.1.2` must report `status=passed`,
  `failed_checks=0`, `mutates_releases=false`, and `network_required=false`.
- The release attestation plan is
  `examples/release-preview/release-attestation-plan.v0.1.example.json`.

## Operator Notes

Treat this release as a preview of AO Forge release controls and factory
contracts. Do not present it as production-stable until Production Promotion
passes for this tag.

Before publishing, confirm that:

- the public tag is signed by an active signer and points at the intended commit;
- the uploaded archives match the supported preview artifacts above;
- `checksums.txt` matches every uploaded archive;
- attestation evidence is attached or linked according to the attestation plan;
- these release notes contain only public repository information.

## Known Limitations

- AO2 execution remains governed by the adapter and gate path.
- Release Attestation produces and verifies GitHub Artifact Attestations.
- Release Publish creates a guarded draft release, but making that draft public
  still requires maintainer review.
- Production Promotion is an evidence gate; it does not publish releases or edit
  release notes.
- AO2 Pulse should be used only as a local-only, non-mutating task assistant
  until AO Forge's release policy surface is stronger.
- v0.1.1 was rehearsal-only and should not be treated as a published release.
